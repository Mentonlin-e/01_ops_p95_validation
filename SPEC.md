# Контракт p95 для этой работы

Используется **nearest-rank**, без интерполяции. Это явно выбранное правило
комплекта; в других инструментах определения процентилей могут отличаться.

Для N непустых наблюдений: отсортируйте значения по возрастанию, найдите ранг
k = ceil(0.95 × N), считайте ранги с 1 и выберите k-е значение. В Python индекс
массива считается с 0. Исходный список не меняется, дубликаты сохраняются.

`p95(values)` принимает список конечных неотрицательных чисел int/float,
исключая bool. Возвращает число из исходной выборки. Пустой список,
отрицательное, NaN, Infinity и нечисловое значение вызывают ValueError.

CLI читает UTF-8 CSV: request_id,status,elapsed_ms. ID непустые и уникальные.
status: ok либо timeout. Для ok время обязательно, конечно и >= 0.
Для timeout elapsed_ms пусто: точное время завершения неизвестно.
Повреждённая строка останавливает чтение целого файла с номером строки.

p95 вычисляется только по завершённым наблюдениям, отдельно выводятся общее
число попыток, число тайм-аутов и их доля. При наличии тайм-аутов полученное
p95_success_ms нельзя назвать p95 всех попыток. Тайм-аут не равен нулю,
среднему или настроенному пределу ожидания.

Если успешных наблюдений нет, p95_success_ms = null. Если CSV содержит только
заголовок, CLI сообщает об ошибке пустого набора. Все времена здесь в мс.
