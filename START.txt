01. ПРОВЕРКА АЛГОРИТМА p95
МИП-2: 20.11.2026. Та же ступень для МИП-3: 23.11.2026.
Формат и срок сообщает преподаватель.

1. Полностью распакуйте ZIP. Прочитайте TASK.md.
2. Нужен установленный Python 3.10 или новее. Пакеты из интернета не нужны.
3. Откройте терминал в папке с этим файлом.
4. Проверьте Python: Windows: py -3 --version; macOS/Linux: python3 --version.
5. Выполните (ниже python замените на py -3 или python3):
   python run.py --input data/regular.csv
   python -m unittest discover -s tests -v
6. В тесте candidate на исходной версии ожидается FAIL: это объект проверки,
   а не поломка запуска. Остальные ошибки нужно разобрать по сообщению.
7. Меняйте starter/p95_candidate.py и дополняйте tests/test_student.py.
   Результаты фиксируйте в REPORT_TEMPLATE.md, сохранив отдельную копию.

START.txt: запуск. TASK.md: задание. SPEC.md: точный контракт.
run.py: готовый CLI. starter/: проверяемый алгоритм. tests/: тесты.
data/: только синтетические исходные значения; это не настоящие измерения.

Если Python отсутствует, запросите у преподавателя разрешённый способ запуска.
Не устанавливайте случайные программы и не выдавайте незапущенный тест за успех.
Интернет, браузер, сервер, pip и учётные записи для работы не нужны.
